WHAT CHANGED
Badge hierarchy: Stopped/Declined → desaturated red (resolved negative). Pending → muted neutral. Urgent owns full danger.
Success: Pushed darker green. Reads as "green" not "gray-green."
Info/Running: Pushed deeper blue. Distinct from muted text.
Warning: Pushed to true amber. No longer reads as "brown."
Danger: Pushed to true red. Clearly danger, not dusty rose.
Muted backgrounds: Bumped alpha to 10-12%. Tints the card without being heavy.
