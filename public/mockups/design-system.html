02 · Typography
Geist Sans + Geist Mono
Sans = human layer (headings, nav, buttons, chat, labels). Mono = agent layer (activity feed, status badges, thinking blocks, tool output). The font signals who produced this, not the data type.

03 · Components
UI Specimens
Core interactive elements and data display patterns. All use CSS variable tokens — no hardcoded colors.
Buttons
Status Badges (mono) — agent-produced states
Done Running Paused Pending Stopped Declined
Danger reserved for "act now." Stopped/Declined use desaturated red — ended negatively but resolved. Pending is neutral.
Alert Pills (sans) — human-facing urgency
⚠ Urgent ● Needs attention
Urgent owns the full danger/destructive color. Needs attention uses warning. These are UI labels (sans), not agent states (mono).
Agent State Indicator — sidebar chat-row status
Running · Pulling HRIS Approve schedule Review complete
Component: <AgentStateIndicator state detail /> (src/components/ui/agent-state-indicator.tsx). States: running, needs-approval, done, idle (renders nothing). Icons are filled for terminal/blocked states; running uses a bold-weight outline spinner. The detail string is auto-sentence-cased (e.g. "pulling HRIS" → "Pulling HRIS"); running additionally prefixes "Running · ".
