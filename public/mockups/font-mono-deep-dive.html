Mono Pairings — Deep Dive

Three font families with matched monospace companions. Mono is used intentionally: it signals the agent's work — thinking, tool calls, extracted data, execution status. Everything else stays sans.

Mono intent study → The design rationale
◆ The rule: If the agent computed it, extracted it, or is actively doing it — mono. If a human wrote it, would say it, or it's UI chrome — sans. Mono is the agent's voice showing through.
