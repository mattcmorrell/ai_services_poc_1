B — Floating Center 2

A — Framed Content: Sidebar + Header use secondary, Chat uses card (brightest), Plan uses background. The navigation "frames" the bright content area. Plan is slightly recessed.
B — Floating Center: Sidebar uses background (recessed), Chat uses card (elevated), Plan uses card with a primary-tinted left border. Sidebar sinks back, content + plan float forward.
C — Tinted Nav: Sidebar uses accent (theme-colored surface), Header uses secondary, Chat uses card, Plan uses muted. Sidebar takes on each theme's personality.
